# 可保存、可分享的研究学习路径

## 功能范围

学习路径将知识库里的资料、概念、代码、实验或自定义行动步骤编排为有顺序的研究讲解。每条路径包含：

- 路径标题、学习目标和适用说明；
- 整条路径的完成条件；
- 最多 100 个有序步骤；
- 每一步的知识对象引用、讲解提示、完成条件和预计用时；
- 草稿／已发布状态，以及发布后的只读分享链接。

## 使用流程

1. 在左侧打开“研究学习路径”，输入标题并新建路径。
2. 填写学习目标、路径说明和整体完成条件。
3. 从知识库加入资料，或添加不关联知识对象的独立步骤。
4. 为每一步填写讲解提示、完成条件和预计用时，并使用上下按钮调整顺序。
5. 保存草稿；准备好后点击“发布分享”。
6. 复制链接或打开分享页预览。分享页不提供编辑控件。
7. 点击“停止分享”后，旧令牌立即失效；重新发布会生成新链接。

发布前必须具备学习目标、整体完成条件、至少一个步骤，并且每一步都有完成条件。草稿不受这些限制。

## 分享边界

当前版本仍是无账号的本地个人工作区。分享链接使用不可猜测令牌并提供只读页面，但它不是完整的身份验证或权限系统：

- 默认只监听 `127.0.0.1`，链接只能在运行项目的电脑上打开；
- 若团队自行远程部署，能够访问该服务的人也可能访问其他无鉴权接口；
- 面向公开互联网部署前，需要增加账号、访问权限、HTTPS、速率限制和审计日志。

分享页只展示路径目标、说明、步骤、知识对象标题／摘要与完成条件，不提供修改按钮。

## 数据与备份

学习路径保存在 PostgreSQL 的 `learning_paths` 和 `learning_path_steps` 表中。数据库迁移版本为 `V004`。完整 ZIP 备份格式升级为版本 3，仍兼容导入版本 1 和版本 2 的旧备份；旧备份恢复后学习路径为空。
